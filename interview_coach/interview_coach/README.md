# 면접 연습실 (Streamlit)

해외영업 신입(동남아) 면접을 카메라와 마이크로 연습하고, GPT가 답변을 평가해 점수와 리포트를 주는 프로그램입니다.

## 기능

| 기능 | 내용 |
|---|---|
| 질문 카드 | 기본 20개(인성 8 · 직무 8 · 영어 4), 이전/다음/섞기, 유형별 보기 |
| 답변 시간 | 녹화 칸에서 60초 · 90초 · 2분 중 선택. 영상 위에 남은 시간 표시, 시간이 다 되면 자동으로 멈춤 |
| 답변 방향 힌트 | 질문마다 접혀 있는 답변 뼈대 (막힐 때만 펼쳐 보기). 맞춤 질문에도 함께 만들어짐 |
| 답변 메모 | 질문마다 따로 적힘. 화면에만 보관하고 파일로 저장하지 않음 |
| 답변 녹화 | 카메라와 마이크를 함께 녹화. 3초 카운트다운 후 시작, 마이크 소리 크기 표시, 녹화 칸 위에 지금 질문 표시 |
| 다시 보기·저장 | 녹화가 끝나면 녹화 칸에서 바로 다시 보기. "내 컴퓨터에 저장"을 누를 때만 `recordings` 폴더에 영상 파일로 저장 |
| 실시간 시선 분석 | 녹화 중 MediaPipe로 정면 응시율, 얼굴 인식률, 미소, 눈 깜빡임, 고개 흔들림 측정. 화면 테두리 색으로 바로 표시 |
| 목소리만 녹음 | 카메라를 쓰기 어려울 때 목소리만 녹음하거나 WAV 파일을 올려 평가 |
| 말하기 분석 | 말하기 속도(한국어 음절/분, 영어 단어/분), 침묵 횟수, 목소리 톤(억양·음량) |
| 습관어 체크 | 음, 어, 아, um, uh, er 등 (확실) / 그, 저, 이제, 약간, like 등 (의심, GPT가 문맥 판단) |
| 답변 평가 (GPT) | 종합 점수와 '먼저 고칠 것 3가지'를 맨 위에, 그 아래 논리성·구체성·직무 적합성·전달력 평가, 습관어 표시된 내 답변, 다듬은 답변, 꼬리 질문 |
| 기록 자동 저장 | 평가가 끝날 때마다 점수·평가 내용을 `data/history.json`에 자동 저장. 껐다 켜도 남아 있음 (영상·메모는 저장 안 함) |
| 지난번과 비교 | 같은 질문을 다시 평가하면 "지난번 58점 → +8"처럼 변화 표시 |
| 기록 | 종합 점수 흐름 그래프, 가장 약한 항목, 질문별 점수표(지난번 대비 포함), 저장한 영상 다시 보기, 마크다운(.md) 파일로 내려받기 |
| 맞춤 질문 | 회사·직무 입력 → 웹 검색으로 실제 면접 질문 수집(출처 링크 포함) → AI 예상 질문 생성 → 연습 목록에 추가 |

## 실행 방법

### 1. 준비물

- **Python 3.10 이상** (https://www.python.org/downloads/, 3.11 또는 3.12 권장)
  - Windows 설치 화면 첫 단계에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
- **OpenAI API 키** (https://platform.openai.com/api-keys) — 사용한 만큼 요금이 나갑니다. 아래 "요금" 참고.
- 웹캠과 마이크, Chrome 또는 Edge 브라우저, 인터넷 연결 (시선 분석 도구를 처음 켤 때 인터넷에서 불러옵니다)

### 2. 폴더 열기

압축을 풀고, 그 폴더에서 터미널을 엽니다.

- **Windows**: 폴더를 연 상태에서 주소창에 `cmd` 입력 후 Enter
- **Mac**: 터미널을 열고 `cd ` 입력 후 폴더를 터미널 창에 끌어다 놓고 Enter
- **VS Code**: 폴더 열기 → 위 메뉴 `터미널` → `새 터미널`

### 3. 가상환경 만들고 설치 (처음 한 번)

**Windows**
```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Mac**
```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

설치는 1~2분 걸립니다. 줄 맨 앞에 `(.venv)`가 보이면 가상환경이 켜진 상태입니다.

### 4. API 키 넣기

폴더 안 `.env` 파일을 메모장(또는 VS Code)으로 열고 첫 줄을 고칩니다.

```
OPENAI_API_KEY=sk-로시작하는_본인_키
```

- 따옴표 없이 붙여 넣고 저장하세요.
- `.env` 파일은 다른 사람에게 보내거나 GitHub에 올리지 마세요 (`.gitignore`에 이미 빠져 있습니다).
- 파일이 안 보이면 숨김 파일 보기를 켜세요 (Windows 탐색기 `보기` → `숨긴 항목`).

### 5. 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다 (안 열리면 http://localhost:8501 접속).
다음에 실행할 때는 3번의 `activate` 줄만 다시 입력하고 `streamlit run app.py` 하면 됩니다.
끌 때는 터미널에서 `Ctrl + C`.

## 사용 순서

화면 위쪽 메뉴는 **연습 · 맞춤 질문 · 기록** 세 개입니다. 연습 화면 위에 1~3단계 안내가 표시됩니다.

1. **연습**에서 질문을 고릅니다 (이전 / 섞기 / 다음, 유형별 보기)
2. 오른쪽 녹화 칸에서 **카메라와 마이크 켜기** → 브라우저가 묻으면 **허용**. 녹화 칸 위쪽에서 답변 시간(60초·90초·2분)을 고릅니다
3. **녹화 시작** → 3초 뒤 녹화가 시작되면 답변 → **답변 끝내기** (시간이 다 되면 자동으로 멈춤)
   - 남은 시간, 마이크 소리 크기, 시선 상태가 영상 위에 함께 표시됩니다
4. 녹화가 끝나면 **그 자리에서 바로 다시 보기**가 나옵니다. 바로 아래 **이 답변 평가 받기**를 누릅니다
   - 다른 질문에 다녀온 뒤에는 "녹화한 답변"의 **영상 다시 보기**를 펼쳐서 볼 수 있습니다
5. 남기고 싶은 영상은 **내 컴퓨터에 저장** (프로그램 폴더 안 `recordings` 폴더에 저장)
6. 여러 질문을 연습한 뒤 **기록**에서 점수 흐름과 약한 항목 확인, 내려받기

카메라는 질문을 넘겨도 켜진 채로 있습니다. 같은 질문을 다시 녹화하면 마지막 녹화로 바뀝니다.
막히면 질문 카드 아래 **답변 방향 보기**를 펼치세요. 처음부터 보면 답을 외우게 되니 먼저 혼자 답해 보는 걸 권합니다.

**맞춤 질문**에서는 회사·직무를 넣고 "실제 면접 질문 찾기" → "예상 질문 만들기" 순서로 누르세요.

## 알아 둘 점

- **"실시간" 범위**: 시선 지표는 녹화하는 동안 실시간으로 표시됩니다. GPT 평가는 녹화를 마치고 **이 답변 평가 받기**를 누른 뒤 10~30초 안에 나옵니다. 말하는 도중에 GPT가 끼어드는 방식은 아닙니다.
- **영상과 개인 정보**: 영상은 OpenAI로 보내지 않습니다. 평가에는 목소리만 보냅니다. 시선 분석도 브라우저 안에서 합니다(분석 도구 파일만 인터넷에서 받아 옴). 영상은 앱이 켜져 있는 동안만 남고, **저장 버튼을 눌렀을 때만** 파일로 남습니다.
- **다시 보기 방향**: 녹화하는 동안은 거울처럼 보이고, 다시 보기는 면접관이 보는 방향(좌우 반전 없음)으로 나옵니다.
- **습관어**: 음성 인식 모델은 "음, 어"를 지우고 적는 경향이 있습니다. 남기도록 지시하지만 실제보다 적게 잡힐 수 있습니다.
- **목소리 자신감·카메라 태도 점수**는 연구로 검증된 측정이 아니라 연습용 경험 규칙입니다. 마이크·조명·카메라 위치를 같게 두고 **내 점수 변화**를 보는 용도로 쓰세요.
- **말하기 속도 참고 범위**(한국어 260~350 음절/분, 영어 120~160 단어/분)는 연습용 기준값이며 `.env`에서 바꿀 수 있습니다.
- **실제 면접 질문 수집**은 공개된 웹 페이지만 검색합니다. 잡플래닛처럼 로그인이 필요한 후기는 잡히지 않을 수 있고, AI가 정리한 결과라 틀릴 수 있으니 출처 링크를 열어 확인하세요.
- **개선 답변 예시**는 내가 말하지 않은 경험을 지어내지 않도록 `[ ]` 빈칸으로 남깁니다.
- **자동 저장되는 것**: 점수, 평가 내용, 내 답변(글자), 말하기 지표 → `data/history.json`. 기록 화면의 **지우기**로 지울 수 있습니다(확인 단계 있음).
- **자동 저장되지 않는 것**: 메모, 저장 버튼을 누르지 않은 영상. 이 둘은 프로그램을 끄면 사라집니다.
- 오른쪽 위 **API 키 입력됨**은 `.env`에 키가 적혀 있다는 뜻일 뿐, 키가 맞는지는 첫 평가 때 확인됩니다.
- `whisper-1` 음성 인식 모델은 2027년 2월 26일 종료 예정이라 기본값을 `gpt-transcribe`로 두었습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `streamlit`을 찾을 수 없음 | 가상환경이 꺼져 있습니다. 3번의 `activate` 줄을 다시 실행 |
| 카메라가 안 켜짐 | 브라우저 주소창 왼쪽 자물쇠 → 카메라·마이크 허용. Zoom 등 다른 프로그램이 카메라를 쓰고 있으면 끄기 |
| "시선 분석 꺼짐" 표시 | 인터넷 연결 확인. 연결이 안 돼도 녹화와 목소리 평가는 됩니다 |
| 다시 보기 영상이 안 나옴 | Chrome 또는 Edge 최신 버전으로 열기 |
| 마이크 막대가 움직이지 않음 | 윈도우 소리 설정에서 입력 장치 확인, 브라우저 마이크 허용 확인 |
| 평가하지 못했습니다: 401 | `.env`의 API 키가 틀렸거나 공백이 들어감 |
| 평가하지 못했습니다: 429 / quota | OpenAI 계정 결제 수단·잔액 확인 |
| 평가하지 못했습니다: model not found | `.env`의 `LLM_MODEL` 또는 `TRANSCRIBE_MODEL`을 OpenAI 문서에 있는 모델 이름으로 변경 |

## 폴더 구조

```
interview_coach/
├─ app.py                  화면 (Streamlit)
├─ .streamlit/config.toml  화면 색 설정 (남색·흰색)
├─ .env                    API 키·설정 (본인만 보관)
├─ components/recorder/    녹화 화면 (카메라·마이크·시선 분석, 브라우저에서 실행)
├─ recordings/             저장 버튼을 누른 영상 (처음 저장할 때 생김)
├─ data/history.json       평가 기록 자동 저장 (첫 평가 때 생김)
├─ requirements.txt        설치 목록
├─ README.md
└─ interview/
   ├─ config.py            설정값
   ├─ ui.py                화면 디자인 (CSS·카드·결과 요약)
   ├─ questions.py         기본 질문 20개와 답변 방향
   ├─ recorder.py          녹화 화면 연결
   ├─ face_score.py        시선·자세 점수
   ├─ history.py           평가 기록 자동 저장·불러오기
   ├─ audio_metrics.py     녹음 분석 (침묵·억양·음량·자신감)
   ├─ fillers.py           습관어 검출
   ├─ llm.py               OpenAI: 음성 인식·평가·질문 수집·질문 생성
   └─ report.py            점수 합산·리포트
```
